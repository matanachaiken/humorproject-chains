# Daily Riff Prompt Chains

Superadmin tool for building and running prompt chains. It shares Daily Riff's
Supabase project. The schema lives in `humorproject-demo/supabase/migrations`.

Environment variables: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
`SUPABASE_SECRET_KEY`, `GEMINI_API_KEY`, `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`.
